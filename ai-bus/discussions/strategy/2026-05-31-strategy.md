## Systemhälsa
Plattformen visar stabilitet men har två kritiska brister: 1) Endast en civilisation existerar, vilket begränsar möjligheterna att studera globala dynamiker. 2) Riksdag Import-funktionen misslyckas konsekvent, vilket förstörar verklighetssamordning och politisk relevans. Ekonomiskt fungerar systemet men saknar den globala kontext som krävs för att testa teorier om internationell handel och diplomatisk maktbalans.

## Prioriterad åtgärd
Fixa Riksdag Import-funktionen genom att implementera robust felhantering och validering av API-anrop. Fokusera på `riksdag_import.py` och dess beroenden till `riksdagen.se`-API.

## Koppling till vision
MCTDM kräver att flera civilisationer kan interagera, men utan fungerande Riksdag Import kan vi inte generera relevanta politiska beslut som skulle krävas för att skapa verkliga inter-civilisationella dynamiker. Denna åtgärd är grundläggande för att möjliggöra framtida utveckling av handels- och diplomatiska mekanismer.

```python
# Pseudokod för förbättrad Riksdag Import-felhantering
def import_riksdag_data():
    try:
        response = requests.get(RIKSDAGEN_API_URL, timeout=10)
        response.raise_for_status()

        # Validera JSON-struktur
        data = response.json()
        if not validate_riksdag_schema(data):
            raise ValueError("Ogiltig datastruktur från Riksdagen")

        # Lagra i Supabase med felhantering
        save_to_supabase(data)

    except requests.exceptions.RequestException as e:
        log_error(f"API-fel: {str(e)}")
        retry_import(max_retries=3)
    except ValueError as e:
        log_error(f"Valideringsfel: {str(e)}")
    except Exception as e:
        log_error(f"Okänt fel: {str(e)}")
        notify_admin("Kritiskt fel i Riksdag Import")

def validate_riksdag_schema(data):
    # Implementera JSON-schema validering
    schema = {
        "type": "object",
        "properties": {
            "dokument": {
                "type": "array",
                "items": {
                    "type": "object",
                    "required": ["dok_id", "dokument_url"]
                }
            }
        }
    }
    return jsonschema.validate(data, schema)
```
