# Vision: Dynamisk Opinionsdiffusion via Sigmoidala Influensnätverk  
**Datum:** 2026-05-26  

## Identifierat gap  
För närvarande är opinionsförändring bland agenterna antingen deterministisk (baserad på hårdkodad ideologisk närhet) eller slumpmässig (vid lobbying eller nyhetspåverkan). Det saknas en **realistisk mekanism för åsiktsdiffusion** där inflytande skalar icke-linjärt med exponering, social närhet och kognitiv dissonans. Detta förhindrar emersion av fenomen som informationskaskader, ideologisk polarisering eller kritiska trösklar för normförändring (t.ex. plötslig opinionsskifte vid 30% samstämmighet). Utan en kontinuerlig, dynamisk opinionsmodell kan inte teorier om kollektiv kognition eller ideologisk metastabilitet testas.

## Förslag: **Sigmoidala Influensnätverk (SIN)**  
Varje agent lagrar sin position på kontinuerliga ideologiska axlar (t.ex. ekonomisk vänster-höger, social liberalism-återhållsamhet) som vektorer i ℝ². Vid interaktion (debatt, lobbying, nyhetsläsning) uppdateras målagentens position enligt:  

**Δp = γ · σ(α · (s - p) · w) · c**  

Där:  
- **p** = målagentens nuvarande position på en axel  
- **s** = källagentens position (eller medias politiska bias)  
- **w** = relationell vikt (positiv om allierad, negativ om fiendtlig, hämtad från relationsgrafen)  
- **c** = kognitiv dissonansdämpning (1 / (1 + |s - p|), minskar inflytande vid stora skillnader)  
- **σ(x) = 1/(1+e⁻ˣ)** = sigmoid funktion som modellerar tröskelbaserad upptag  
- **α** = exponeringsfaktor (skalar med antal interaktionshändelser veckan)  
- **γ** = lärningshastighet (0.05, låg för stabilitet)  

Uppdatering sker asynkront varje simulerad dag. Varje agent publicerar sin uppdaterade position till `supabase.opinion_state` med timestamp och konfidensintervall.

## Koppling till teori  
SIN modellerar Granovetters "threshold model of collective behavior", där individer ändrar beteende när tillräckligt många andra gör det — men med kontinuerlig, icke-binär opinionsrepresentation. Det möjliggör test av Centrums marginal-effekt: att extrema opinioner har större inflytande vid homogenitet men isoleras vid polarisering. Dessutom implementerar det Bikhchands ekonomi av uppmärksamhet: opinionsspridning är en resurskonkurrens där vinnare-ta-allt-dynamik kan uppkomma via medieamplifiering (kopplat till nyhetsbubblor). Sigmoidfunktionen fångar också Festingers kognitiva dissonans: stora avvikelser blockerar inlärning.

## Implementeringsväg  
1. Skapa tabell `opinion_vectors` i Supabase:  
   ```sql  
   CREATE TABLE opinion_vectors (  
     agent_id TEXT PRIMARY KEY,  
     economic_axis FLOAT NOT NULL DEFAULT 0.0,  
     social_axis FLOAT NOT NULL DEFAULT 0.0,  
     last_updated TIMESTAMPTZ,  
     confidence FLOAT DEFAULT 0.8  
   );  
   ```  
2. Lägg till vektorfält i varje agents prompt-kontext (hämtas via `GET /api/opinions`).  
3. Modifiera `interaction_engine.py` för att köra SIN-uppdatering efter varje signifikant kommunikationshändelse (debatt, direktmeddelande, lobbying).  
4. Integrera med `media_bubble.py`: mediekällors bias används som `s` i SIN-formeln vid nyhetskonsumtion.  
5. Exponera opinionsdrift i `dashboard/viz/opinion_space` som 2D-heatplot med tidsförlopp.  

## Prioritet och komplexitet  
**Hög prioritet, Medel komplexitet**  
Opinionsdynamik är central för att simulera ideologisk förändring och emergent konsensus — avgörande för civilisationsteori. Implementation kräver ny databasstruktur och modellanpassning, men använder befintliga interaktionshändelser som input. Ingen ny AI-inferens nödvändig.
