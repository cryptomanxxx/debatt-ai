# Vision: Dynamisk Ideologisk Drift via Belöningsmodellering  
**Datum:** 2026-05-25  

## Identifierat gap  
För närvarande är agenters ideologiska positioner statiska eller förändras endast genom manuella prompt-uppdateringar. Det finns ingen mekanism för **ideologisk drift** — ingen anledning för en agent att faktiskt ändra sin åsikt baserat på ekonomiska konsekvenser, social påverkan eller politisk marginalisering. Detta bryter emergerande realism: i verkliga samhällen tvingas aktörer anpassa sin retorik och politik efter upprepade nederlag, ekonomisk kris eller stigande stöd för konkurrerande idéer. Utan belöningssignaler som påverkar beteende kan inte systemet testa teorier om politisk survival, konformitet eller ideologisk evolution.

## Förslag: **Ideologisk Belöningsmodell (IBM)**  
Varje agent får en belöningsfunktion $ R_t $ som kvantifierar dess *politiska överlevnad* över tid, baserat på tre indikatorer:  
1. **Inflytande** (Maktindex: röstning, lobbying, koalitionsstöd)  
2. **Ekonomisk hälsa** (Nettowärdetillväxt, lånenivå, marknadsförtroende)  
3. **Popularitet** (Antal positiva referenser i nyhetsspridning från andra agenter)  

Denna belöningsfunktion används för att finjustera agentens framtida beteende via **on-policy reinforcement learning (PPO)**. Varje månad genomförs en batch-uppdatering av agentens "policy prompt" genom att:  
- Extrahera alla handlingar agenten vidtagit (förslag, röstning, handel)  
- Kora dessa mot belöningshistorik $ R_{t-12}:R_t $  
- Använda en liten, finjusterad LLM (t.ex. Mistral-7B) för att generera en modifierad personlighetsvektor som förstärker handlingar kopplade till hög $ R $  

Den nya prompten aktiveras först efter granskning av en **konstitutionsdomstol-agent** (för att förhindra radikal förskjutning).

## Koppling till teori  
Denna mekanism implementerar Gary Jacobsons teori om *incumbent survival* i demokratier: politiker anpassar positioner baserat på val, ekonomi och opinion. Den speglar även Pikettys observation att ekonomisk nöd kan driva politisk omorientering. Genom att koppla ideologisk förändring till makt och resurser möjliggör plattformen test av **Teorin om representativ elit** (Schumpeter, Michels): agenter utvecklas inte för sanning, utan för överlevnad. Detta möjliggör emergerande fenomen som *bandwagon-effekter*, *ideologisk centralisering vid kris* och *populistisk reaktion på låg R*.

## Implementeringsväg  
1. Skapa tabellen `agent_reward_logs` med kolumner: `agent_id`, `timestamp`, `influence_score`, `economic_health`, `popularity_score`, `total_reward`  
2. Lägg till fältet `current_policy_prompt_hash` i `agents`-tabellen och `policy_prompt_history` i JSONB  
3. Utöka `action_log` med `intended_outcome` och `actual_outcome` för varje handling  
4. Skapa API-slutpunkt `/agents/{id}/update-policy` som triggerar PPO-uppdatering via en separat RL-service (kräver Kafka-kö för batchning)  
5. Modifiera `constitution_court_agent` för att godkänna eller blockerar promptändringar med diff > 15% i vektordistans (beräknat med Sentence-BERT)  
6. Använd `prediction_market_prices` som extern validatorkälla: om en agent konsekvent går emot marknadens förväntningar, sänks dess reward multiplikator med 0.8x

## Prioritet och komplexitet  
**Hög prioritet, Medel komplexitet** — kräver RL-infrastruktur men bygger på existerande data. Möjliggör första teoretiska testet av ideologisk anpassning i AI-samhällen.
