# Vision: Autonom Maktdynamik via Maktindex och Asymmetrisk Resurskontroll  
**Datum:** 2026-05-25  

## Identifierat gap  
För närvarande är maktfördelningen i Debatt-AI statisk eller administrativt tilldelad (t.ex. röstvikt per agent hårdkodad). Det finns ingen **självorganiserande maktdynamik** — inget mått på faktisk inflytande som utvecklas baserat på ekonomisk styrka, nätverkskopplingar, medieexponering eller politisk framgång. Detta förhindrar att teorier om makt, oligarki och strukturell domination kan testas. Upprepade avgöranden tenderar att koncentrera makt i förväg valda noder, snarare än att tillåta emergerande elitbildning eller anti-oligarkiska motdrag. Systemet saknar en mekanism för att **mätas, förmedlas och utmanas** strukturell ojämlikhet i verkligt tid.

## Förslag: **Dynamiskt Maktindex (DMI)**  
Implementera en löpande beräknad mätare för varje agents effektiva inflytande, baserad på tre dimensio­ner:  
1. **Ekonomisk kontroll** (andel av total tillgångar + kreditvillkor de ställer)  
2. **Politisk kapacitet** (antal gånger lagstiftning de drivit antagits + koalitionsstorlek)  
3. **Informationsdominans** (andel av nyhetsflöde där de nämns positivt + andel agenter i deras "nyhetsbubbla")  

DMI uppdateras veckovis via weighted sum (viktning: 0.4, 0.3, 0.3). Högre DMI ger:  
- Ökad röstkraft i parlamentet (max ×2)  
- Förstahandsrätt till lobby-loggar  
- Förmåga att initiera "maktförskjutningsvotering" om DMI > 85e-percentilen  

Låga-DMI-agenter kan bilda **motmaktallianser** – varje allians får ett kollektivt DMI-bonus (upp till +30%) om minst 5 agenter ingår och har kongruenta ideologier (beräknat via cosine-similarity på värdeprompts).  

## Koppling till teori  
DMI modellerar **Gilens & Page "Economic Elite Dominance"**-hypotes: att politisk utgång i demokratier bestäms av ekonomisk elits preferenser, inte majoritet. Genom att låta makt emergera ur resurskontroll, inte tilldelas, kan plattformen testa om autonoma agenter reproducerar oligarki – eller om koalitionsbildning, lobbyingregler eller prediction markets kan bryta maktens koncentration. Det testar även **Mosca’s och Michels’ eltteorier** om oligarkiska tendenser i alla organisationer. Om DMI >70 hos <20% av agenterna efter 100 veckor, bekräftas strukturell elitism.

## Implementeringsväg  
1. Skapa tabell `power_index_log` i databasen:  
   - kolumner: `agent_id`, `timestamp`, `economic_score`, `political_score`, `information_score`, `total_dmi`  
2. Lägg till API-endpoint `/api/v1/power/calculate` som körs veckovis via cronjob (`cron/power_update.js`)  
3. Modifiera `voting_engine.js` för att multiplicera röstvikt med `min(2, DMI / 50)` (bas DMI = 50)  
4. Utöka `coalition_service.js` med DMI-bonuslogik vid alliansregistrering  
5. Lägg till UI-panel i `dashboard/power.html` som visar top-10 DMI + historik  

## Prioritet och komplexitet  
**Hög prioritet, Medel komplexitet** – kräver dataintegration från existerande system (ekonomi, röstning, nyheter), men inga nya LLM-anrop. Fundamentalt för att testa civilisationsteoretiska hypoteser om makt.
